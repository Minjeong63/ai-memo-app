# 📝 PRD: **Memora** – AI 음성 메모장 웹서비스

---

## 1. 제품 개요

**제품명:** Memora
**제품 유형:** AI 기반 웹 메모 애플리케이션
**서비스 형태:** **웹 애플리케이션(Web-based Service)**

### 🧩 개발 배경 및 목적

기존 메모 서비스는 사용자의 메모를 단순 저장하는 데 그치는 경우가 많아, 시간이 지날수록 중요한 정보를 찾기 어렵고 효율적인 활용이 어려워집니다. 특히 회의록, 아이디어, 공부 내용 등 다양한 형태의 메모를 빠르게 작성하고 구조화하는 것이 점점 더 중요해지고 있습니다.

**Memora**는 **AI 메모장 웹서비스**로, 사용자의 음성 또는 텍스트 입력을 받아 **AI가 자동으로 요약 및 분류**해주는 기능을 제공합니다. **STT(Speech-to-Text) 기술**을 통해 빠른 음성 메모 작성이 가능하며, 모든 데이터는 **웹 애플리케이션의 데이터베이스에 저장**됩니다.

### 🎯 제공 가치

* **AI 요약**: 긴 메모를 간결한 핵심 요약으로 제공
* **카테고리 분류**: 자동 분류 기능을 통한 체계적인 메모 정리
* **STT 기반 음성 입력**: 빠른 음성 기반 메모 작성 가능
* **웹 접근성**: 설치 없이 브라우저에서 사용 가능

## 2. 핵심 기능 (Core Features)

### 📝 텍스트 메모 작성
- **기능**: 사용자가 웹 인터페이스에서 직접 텍스트로 메모 작성
- **중요성**: 기본적인 메모 작성 기능으로 모든 사용자에게 필수
- **동작 방식**: React 기반 텍스트 에디터 컴포넌트, 실시간 저장

### 🎤 음성 입력 (STT 변환)
- **기능**: 마이크를 통한 음성 입력을 실시간으로 텍스트로 변환
- **중요성**: 빠른 메모 작성과 접근성 향상
- **동작 방식**: Web Speech API 또는 외부 STT 서비스 연동

### 🤖 AI 요약
- **기능**: 긴 메모 내용을 AI가 자동으로 핵심 요약으로 변환
- **중요성**: 메모의 핵심 내용을 빠르게 파악 가능
- **동작 방식**: OpenAI API 또는 유사 AI 서비스 연동

### 🏷️ 자동 카테고리 분류
- **기능**: 메모 내용을 분석하여 자동으로 적절한 카테고리 분류
- **중요성**: 체계적인 메모 정리와 검색 효율성 향상
- **동작 방식**: AI 모델을 통한 텍스트 분류 및 태깅

### 🔍 검색 기능
- **기능**: 키워드, 작성일, 카테고리별 메모 검색
- **중요성**: 저장된 메모의 효율적인 검색과 접근
- **동작 방식**: 클라이언트 사이드 필터링 및 서버 사이드 검색

### 💾 데이터베이스 저장
- **기능**: 모든 메모 데이터를 안전하게 서버 DB에 저장
- **중요성**: 데이터 영속성과 백업 보장
- **동작 방식**: RESTful API를 통한 CRUD 작업

#### 외부 서비스 연동
- **STT 서비스**: Web Speech API 또는 Google Speech-to-Text
- **AI 요약**: OpenAI GPT API 또는 유사 서비스
- **카테고리 분류**: OpenAI API 또는 Hugging Face 모델

### 🔌 API 및 통합

#### RESTful API 엔드포인트
- `GET /api/memos` - 메모 목록 조회
- `POST /api/memos` - 새 메모 생성
- `GET /api/memos/[id]` - 특정 메모 조회
- `PUT /api/memos/[id]` - 메모 수정
- `DELETE /api/memos/[id]` - 메모 삭제
- `POST /api/memos/voice` - 음성 메모 처리
- `POST /api/memos/summarize` - AI 요약 생성

#### 외부 API 통합
- **STT API**: 음성-텍스트 변환
- **AI API**: 텍스트 요약 및 분류
- **파일 스토리지**: 오디오 파일 저장 (Vercel Blob 또는 AWS S3)

## 7. 위험 요소 및 완화 방안 (Risks and Mitigations)

#### STT 기술의 정확도
- **위험**: 음성 인식 정확도가 낮을 경우 사용자 경험 저하
- **완화 방안**: 
  - 여러 STT 서비스 비교 테스트
  - 사용자 피드백을 통한 정확도 개선
  - 수동 편집 기능 제공

#### AI API 비용 및 제한
- **위험**: API 호출 비용 증가 및 속도 제한
- **완화 방안**:
  - 캐싱 전략 구현
  - 배치 처리로 비용 최적화
  - 무료 티어 활용 및 비용 모니터링

#### 데이터 보안 및 개인정보
- **위험**: 사용자 메모 데이터 유출 위험

  - 데이터 암호화 저장

## ✅ 결론 및 향후 과제

Memora는 브라우저 기반에서 음성과 텍스트로 빠르게 메모하고, AI가 자동으로 요약 및 분류해주는 웹 메모장입니다. 

**초기 버전에서는 핵심 기능인 STT 기반 음성 메모, AI 요약, 카테고리 분류에 집중**하고, 사용자 피드백을 바탕으로 검색 고도화 및 시각화 통계 기능을 순차적으로 확장할 예정입니다.

**성공 지표**:
- 월간 활성 사용자 1,000명 달성
- 메모 작성 완료율 80% 이상
- 사용자 만족도 4.5/5.0 이상
- 음성 메모 사용률 30% 이상
